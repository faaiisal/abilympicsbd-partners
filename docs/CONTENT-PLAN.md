# Abilympics Bangladesh — Content Plan

This document defines the content structure for the Abilympics Bangladesh partnership website.

The website is an English-only, accessibility-first partnership and sponsorship landing page.

---

## 1. Website Identity

### Organization

Abilympics Bangladesh

### Website Purpose

The website is designed to:

- Present Bangladesh's Abilympics journey
- Highlight the 2023 international participation
- Introduce the Helsinki 2027 journey
- Attract sponsors and partners
- Explain partnership opportunities
- Showcase participants and achievements
- Provide media and social updates
- Provide an accessible contact and partnership inquiry experience

### Main Message

> Bangladesh to the Global Stage.

### Brand Statement

> Empowering Ability. Inspiring Excellence. Representing Bangladesh.

# 23. Accessibility Requirements

The website must consider:

- Low Vision
- Invisible Disabilities
- Visual Disabilities
- Legal Blindness
- Complete Blindness
- Color Blindness
- Deaf-Blindness

Implementation requirements:

- Semantic HTML
- Proper heading hierarchy
- Keyboard navigation
- Visible focus
- Screen-reader-friendly controls
- Descriptive alt text
- Captions-ready video
- Transcript-ready video
- Strong contrast
- No color-only indicators
- Accessible forms
- Accessible carousel controls
- Reduced-motion support
- Large touch targets

---

# 24. Content Rules

The development team must not:

- Invent participant information
- Invent medals
- Invent sponsors
- Invent sponsorship benefits
- Invent media coverage
- Invent organization claims
- Invent quotes
- Invent statistics

If information is unavailable, use a clear placeholder or omit the content.

---

# 25. Content Source Strategy

Initial version:

Local typed content.

Recommended structure:

src/content/

- site.ts
- event.ts
- participants.ts
- partners.ts
- stories.ts
- gallery.ts
- media.ts
- faq.ts

Future:

A CMS may replace local content if the project requires non-developer content management.
